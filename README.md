# Downloads Organizer 🎀

A cute pastel macOS app for keeping your Downloads tidy.

- **Home**: a friendlier Finder for your folders
- **School**: sorts downloads into a folder for the current semester
- **Tidy Up**: sorts files into folders by type
- **Clean Out**: finds old files you can send to the Trash
- **My Folders**: cute custom folder icons

It never renames or permanently deletes your files.

## Build

Requires macOS 14+ and the Xcode Command Line Tools.

```bash
./build.sh
open "build/Downloads Organizer.app"
```
